### 1. Matrix-Game 4.0：利用视频模型构建实时可玩游戏世界

**原文标题：** Matrix-Game 4.0: Harnessing Video Models for Real-Time Playable Game Worlds

**摘要：**
从可控视频迈向真正可玩的世界，需要持久的世界状态、可执行的游戏规则以及低延迟交互。我们提出了下一代 Matrix-Game 的路线图，通过可执行游戏测试框架将游戏执行与视觉生成分离，并介绍 Matrix-Game 4.0 作为基于该设计的首个系统。轻量级游戏引擎维护世界状态并执行交互规则，多模态编码智能体将玩家想法转化为游戏代码和动态场景描述，而基于自回归视频模型的渲染器则将引擎渲染的低多边形代理转化为细节丰富的视觉效果，并以动态描述和记忆参考为条件。该框架为视觉生成提供持续引导，并支持以自然语言创建和修改场景与玩法。我们的渲染器在对齐的低多边形与高保真视频对上训练，并蒸馏为因果生成器，以四帧为单位、通过一到两步去噪进行生成。结合针对性的推理优化，Matrix-Game 4.0 可在单块 NVIDIA RTX5090 上实现 480p、60 FPS 的游戏运行，按键到显示延迟为 112ms。单步生成在稳态吞吐下达到 83FPS，峰值 GPU 内存占用为 18.2GiB。在固定提示词下，稳态吞吐在 RTX5080 上也可达到 67FPS，在 RTX5070Ti 上达到 58FPS。我们展示了具有引擎强制机制的可定制射击和驾驶游戏，并发布代码、模型权重和低多边形游戏资源，以支持可玩游戏世界的研究与创作。

### 2. PAR：面向状态跟踪中长度泛化的进度对齐循环

**原文标题：** PAR: Progress-Aligned Recurrence for Length Generalization in State Tracking

**摘要：**
循环语言模型在测试时可运行更多迭代，但额外迭代未必有助于其解决更长的问题。对于序列状态跟踪，最终答案监督并未规定每次迭代应推进多远，而重复更新可能改变循环状态的尺度。我们提出进度对齐循环（PAR），其训练第 k 次迭代的预测以匹配前 k 个操作后的状态，并将循环状态重新缩放到其首次迭代的范数。在 swap-S_5 上，一个至多训练 32 步的 Qwen2.5-0.5B 模型在 512 步时达到 95.5% 的平均全状态准确率，即训练长度的 16 倍；相比之下，同一骨干模型上 RLT 报告为 55.7%，显式思维链为 0.8%。受控 S_5 消融实验表明，移除范数锚定会将外推因子从 16 倍降至 2.2 倍以下，而将进度对齐目标替换为最终答案监督则将其降至至多 8 倍。一个学习到的完成读出机制可在未提供停止深度时选择何时作答。当中间标签不可用时，前缀自蒸馏仅使用最终答案，从较短的问题前缀中诱导出这种对应关系。这些增益适用于各类序列状态跟踪任务，确立了深度外推所需的任务结构。这些发现支持将中间预测与状态尺度联合训练，从而使额外的循环深度对更长问题有用。

### 3. 聚焦式全模态GUI智能体

**原文标题：** Focused Omni-Modal GUI Agents

**摘要：**
图形用户界面（GUI）智能体日益需要在流式全模态观测上执行动作，这些观测涵盖截图、音频、视频、交互历史和设备状态。然而，在每一步都统一暴露完整上下文忽略了一个事实：相关性是短暂且稀疏的；决定某一动作的信号在下一步可能变成干扰。由于已执行动作会反馈到上下文中，这些错误会累积为序列性分心，驱使智能体陷入不可逆的轨迹漂移。我们将这一底层需求表述为聚焦感知：一种逐步自适应、动作充分且非侵入式的表示。我们在FocusGUI中实现了这一点，这是一种轻量级适配器，能够针对步骤特定的决策参考动态优先化多模态通道。它不统一处理所有输入，而是将最相关的证据压缩为紧凑潜在表示，并将其轻量地注入冻结解码器的嵌入中，在不改变其原生参数空间的情况下引导模型注意力。FocusGUI仅通过动作监督训练，既不需要模态相关性标签，也不需要微调骨干模型。在四个全模态骨干模型上，平均而言，相较冻结骨干，它将总体Type Match提升+33.2，将Exact Match提升3.0倍；相较最强现有增强方法，将Type Match提升+30.1。

### 5. S-Agent 2.0：使用通用编程智能体进行空间推理

**原文标题：** S-Agent 2.0: Spatial Reasoning with a General Coding Agent

**摘要：**
空间推理要求模型确定三维空间中物体的位置、它们之间的相互关系以及运动方式。智能体化视觉语言模型（agentic VLMs）近来通过让模型利用三维感知工具主动收集证据，而非单遍作答，在此类任务上取得了大幅提升。即便如此，在许多问题上，工具返回了正确证据，模型却仍未得出正确答案：模型与工具之间的鸿沟——即原始读数转化为可用结论的环节——仍未被填补。我们提出 S-Agent 2.0，一种空间推理智能体，它为现成的通用编程智能体配备命令行感知工具包，并围绕一个原则设计接口：帮助 VLM 闭合证据闭环：获取场景证据，将其保存在持久场景记忆中，并以简明空间语言解释每个读数。该设计保留了编程智能体的完整灵活性，且其处理的每个读数始终以工具的几何信息为依据。在 MMSI-Bench 和 ReVSI 上，该工具包使强开源模型 Qwen3.8-27B 相较无工具的同一智能体分别提升 +13.9 和 +20.5 分，并使强闭源模型 Gemini-3.8-Flash 分别提升 +11.2 和 +9.6 分。在开源骨干模型上，S-Agent 2.0 在 MMSI-Bench 和 ReVSI 上分别达到 66.5 和 82.3，超过同一骨干上的专用系统 SpatialClaw（62.6 和 74.5）；搭配 Gemini-3.8-Flash 时达到 74.1 和 90.5，而后者为 67.0 和 79.7。随着骨干模型能力增强，两种工具带来的增益均会缩小，但 SpatialClaw 在 ReVSI 上的增益缩小幅度大得多，从 +13.2 降至 +2.7，而我们的方法保持在 +9.6。S-Agent 2.0 还可适用于不同的通用编程智能体运行框架，如 Codex 和 Claude Code。

### 6. VLA-Rolling：更少去噪步骤，通过自适应动作复用实现更优控制

**原文标题：** VLA-Rolling: Fewer Denoising Steps, Better Control via Adaptive Action Reuse

**摘要：**
流匹配视觉-语言-动作（VLA）模型通过迭代去噪高斯噪声来生成动作块，但通常仅执行一个较短前缀，随后利用更新后的观测重新规划。在这种滚动时域范式下，未执行的剩余部分——动作尾部——会被丢弃，而下一动作块则从全新噪声重新生成。我们表明，这种被丢弃的尾部保留了可迁移的去噪进展：动作尾部初始化能够在使用更少去噪步骤的情况下匹配或优于原生10步高斯基线。然而，最优去噪预算在不同样本间差异显著，这表明尾部复用应适应更新后的环境。基于这一观察，我们提出VLA-Rolling，一种轻量级推理框架，它通过三个阶段复用动作尾部：动作尾部继承、逐动作置信度估计，以及通过重新加噪与去噪预算分配进行的置信度引导细化，同时底层VLA保持冻结。在LIBERO、MetaWorld、LIBERO-Plus和RoboTwin 2.0上，针对π_{0.5}、SmolVLA、X-VLA和MolmoAct2，VLA-Rolling在全部16个模型—基准组合中降低了动作块推理成本，实现最高1.48倍加速，同时在14个组合中将成功率最高提升15.08个百分点。这些结果表明，动作尾部不仅仅是可丢弃的预测，而是可复用的中间状态，能够实现更高效、更准确的VLA推理。这些结果证明，动作尾部能够支持以更少去噪步骤生成更好的动作。我们的项目见 https://chenbao123ww.github.io/VLA-Rolling/。

### 8. CoEvo-RSI：当执行框架进化时，哪些模型应当跟随？

**原文标题：** CoEvo-RSI: When Harnesses Evolve, Which Models Should Follow?

**摘要：**
模型—执行框架协同进化已成为递归自我改进（RSI）智能体的一种重要范式，使智能体的执行脚手架与内在能力协同演化。我们研究了该范式中持续存在却常被忽视的“大脑—身体失配”问题，即不断演化的执行框架（身体）要求其模型（大脑）尚未习得的行为，或限制了模型已然具备的能力。我们提出 CoEvo-RSI，一个通过智能体驱动、双向历史继承来推进模型—执行框架协同进化的 RSI 框架。借助共享的进化档案与执行反馈，一个元智能体协调执行框架的开发——从历史设计中汲取经验——并进行模型检查点选择或合并，以及在所选执行框架下的后续适配，从而使继承的能力与不断变化的执行需求相匹配，以减少大脑—身体失配。CoEvo-RSI 仅在其自身经拒绝采样的轨迹上使用监督微调（SFT），便使 Qwen3.5-9B 在多种垂直应用中可与更大规模的模型相竞争，包括多智能体故障归因、角色感知的 text-to-SQL 以及智能家居指令遵循。它在 TraceElephant 上超越 DeepSeek-V4-Pro（智能体准确率 +14.16），在 HomeBench VM 上超越 GLM-5.3（成功率 +4.90），凸显了大脑—身体对齐的必要性以及双向历史继承在推进智能体协同进化方面的潜力。

### 10. SolarRenderer：少步生成式参考渲染

**原文标题：** SolarRenderer: Few-Step Generative Reference Rendering

**摘要：**
游戏引擎和编码代理可以指定场景的布局、运动和相机，但要将这种粗粒度结构转化为逼真的视频，需要一个能够遵循该结构并补全其未指定外观的渲染器。现有渲染器受限于单一引擎的表示方式，需要数十个去噪步骤或进行昂贵的自身蒸馏，且其学习所依据的条件与目标视频并不对齐。我们提出SolarRenderer，一种结构条件化的视频渲染器，它通过两个轻量级LoRA对冻结的MiniMax-H3 33B骨干网络进行适配。结构视频在其所描述帧的位置进入骨干网络的原生参考路径，无需类型标识符且仅以纯文本描述，从而使单个控制LoRA能够遵循任意结构表示。从预训练的四步LoRA出发，结构引导的分布匹配以四步完成渲染，比50步采样快12.3倍，同时保持所学到的控制能力。块因果变体将相同设计扩展到流式处理，并实时渲染768p视频。为训练该模型，我们构建了一个帧对齐语料库，包含来自游戏引擎、模拟器和YouTube视频的136K个片段。在分布内测试集和涵盖16种结构表示的泛化基准上的实验表明，SolarRenderer在两者上均达到最先进的结果，并可泛化到11种未见过的表示，包括姿态骨架、绘画和点云。

Lean 可验证生成的声明类型良构，但无法检查其是否表达了用户意图。我们衡量在没有规范 Lean 目标的情况下，陈述自动形式化中编译在多大程度上高估了忠实性。我们的标准要求 Lean 编译通过，且来自不同模型族的两个 LLM 评审员一致同意。在独立随机审计中，该标准在 91.5% 的案例上与人类多数判断一致；它很少接受不忠实输出，但会拒绝一些忠实输出。在 227 个大学水平陈述上对八个系统进行评估，编译输出与接受输出之间的差距为 1.3 至 29.5 个百分点：我们的工具增强智能体编译了 87.2% 的陈述，但仅 57.7% 被接受。对所有智能体拒绝项的人工复核确认，其 29.5 个百分点中有 23.8 个百分点是真实翻译错误。对于七个单次（one-shot）系统的差距，由 Claude Opus 5.5（配合 Lean）与 GPT-6.1 Sol 进行的两阶段评审在这些人工标签上得到验证，发现其中六个系统的差距有 78%–100% 是真实翻译错误。当两个评审之一 GPT-5.2 对在其之后发布的两个模型——GPT-6 Astra 和 Claude Opus 5.5——的翻译进行评分时，它对每个模型接受 83% 的陈述，而单次 GPT-5.2 为 21%。对于这两个模型，同一评审仅将它们的 54 个拒绝项中的 4 个（7%）归类为翻译错误，因此其测得差距的大部分是评审错误而非翻译错误。这与这些系统犯错更少而评审并未相应减少错误的现象一致：系统犯的错误越少，其拒绝项中翻译错误所占比例越小。最后，对该智能体的 2^3 工具消融实验表明，Lean 反馈驱动了其编译增益的大部分，而该增益中近一半未通过语义标准。代码与数据见：https://github.com/grenadeComing/beyond-compilation。

### 45. HumanSkill-4D：在空间与时间中对可动画高斯化身进行免训练语言查询

**原文标题：** HumanSkill-4D: Training-Free Language Querying of Animatable Gaussian Avatars in Space and Time

**摘要：**
我们提出化身指称分割，即根据语言查询选择可动画高斯化身的区域。查询还可以指定姿势或运动，以选择匹配的时间区间。这使用户能够与化身交互，进行局部编辑和运动检查。然而，使用现有语言高斯泼溅方法进行这些选择面临两个挑战：相邻部位和服装难以分离，且可能被间接指称（区域歧义）；而细粒度运动在RGB中可能看起来相似（运动歧义）。我们通过HumanSkill-4D应对这些挑战，这是一个免训练框架，在多个化身之间共享多模态大语言模型（MLLM）和几何算子。对于每个化身，语义记忆将身体部位和服装类别链接到持久的高斯区域和外观描述。MLLM使用类别名称和描述，依据外观、关系或功能来选择类别。为了找到匹配区间，它将算子组合成程序，在存储于运动记忆中的驱动关节轨迹上检查查询条件。这些类别选择和算子输出使选择具有可追溯性，而组合或添加算子可支持新的运动条件。为了评估该任务，我们引入三个人工标注基准，并表明HumanSkill-4D在部位分割以及3D与4D指称分割中优于基线，且记忆紧凑，每个化身仅需数分钟设置。

### 46. TRACE：追踪多模态临床轨迹用于住院患者风险预测

**原文标题：** TRACE: Tracking Multimodal Clinical Trajectories for Inpatient Risk Prediction

**摘要：**
准确的住院患者风险预测需要对随时间不规则累积的异质性临床证据进行建模。该挑战涵盖院内死亡、住院时间延长和再入院，且每项任务具有特定的观察窗口。现有多模态方法结合了结构化健康记录数据、胸部X线片和临床文本，但主要关注模态融合或缺失模态补偿，对单次住院期间时间轨迹的关注有限。我们提出TRACE（多模态临床事件轨迹建模），一种日尺度框架，将临床事件组织为日级轨迹，并将日不变全局背景与日特定局部事件分离，这些事件来源于电子健康记录数据、胸部X线片、放射学报告和出院小结。该轨迹使用时间注意力进行编码，使不可用模态不输出任何标记。表型引导的对比目标进一步在异质性疾病分布下组织住院样本。在来自MIMIC-IV、eICU和MIMIC-III、总计近180,000次住院的队列中，我们在死亡、住院时间和再入院预测上评估TRACE。TRACE在所有九种数据集-任务设置中取得最高AUROC，并在八种设置中取得最高ACC，优于基线方法。消融研究验证了我们的注意力掩码和对比学习，而轨迹级归因可定位与风险相关的住院日和模态。

### 47. 论规模的局限：视觉语言模型中的逆缩放

**原文标题：** On the Limits of Scale: Inverse Scaling in Vision-Language Models

**摘要：**
缩放定律表明，增大模型规模、训练数据和计算量通常会带来单调的性能提升。尽管这一规律在总体层面常常成立，我们提供了系统性证据表明，视觉语言模型（VLM）在子任务层面表现出逆缩放：在同一模型家族内，较大模型在某些特定问题类别上反而比较小模型表现更差。我们评估了来自四个不同模型家族的19个模型，涵盖八个多模态基准（九个评估划分），每个模型回答29,386个问题，总计558,334次模型-问题评估。通过对每个家族中所有模型对进行逐问题成对分析，我们识别出375个子任务-模型对组合表现出逆缩放，涵盖4,342个不同查询，其中较小模型回答正确而较大模型失败，并且我们发现这些模式在独立开发的架构中可复现。我们识别出13个子任务-数据集对在多个家族中表现出逆缩放，这与该现象由任务驱动而非模型特定的判断一致。本研究中受影响最大的领域包括多图像空间推理、视觉感知和大学水平STEM知识，若干情况下准确率差距超过20个百分点，而图表理解似乎相对不受影响。这些发现挑战了增大模型规模会一致提升多模态能力的假设，并表明模型选择应具备任务感知性。

### 48. Slot-JEPA：面向潜在世界模型的对象结构化预测接口

**原文标题：** Slot-JEPA: Object-Structured Prediction Interfaces for Latent World Models

**摘要：**
联合嵌入预测架构（JEPAs）作为一类典型的潜在世界模型，能够提供强语义表示。然而，稠密的图像块表示会向下游预测器暴露冗余接口，下游预测器必须隐式推断空间组织与时间对应关系，这带来三个挑战。首先，对象信息分散于各图像块中，迫使每个下游预测器在建模交互之前冗余地恢复本可跨任务复用的对象结构。其次，跨时间缺乏显式实体对应关系，使历史转移的代价高昂，限制了预测器利用上下文的灵活性。第三，在缺乏显式传输结构的情况下，现有JEPA模型通常采用逐点L1/L2距离；当预测支撑集与目标支撑集基本不相交时，该距离对空间位移不敏感。我们提出基于槽位的联合嵌入预测架构（Slot-JEPA），将稠密表示分解为稳定的语义槽位和随时间变化的空间掩码。该分解只需预训练一次并在下游冻结，即可提供可复用的对象结构化接口。在此基础上，我们的转移记忆预测器（TMP）将视觉转移存储为紧凑掩码，并利用对应槽位的统计量检索有用上下文。其两个分支将槽位特定动态与共享的跨槽位动态分离。我们进一步使用非平衡最优传输（UOT）监督掩码预测，并通过在对齐的预测掩码与目标掩码之间传输概率质量来评估候选方案，从而提供与空间进展更一致的信号。在七个视觉理解基准上，槽位重建特征仍具有可迁移性。在六个平面环境和REALM-JEPA基准上的四个机械臂规划任务中，Slot-JEPA还提升了目标条件规划的性能。

### 49. HRoPE：单应性相对位置编码

**原文标题：** HRoPE: Homography Relative Positional Encoding

**摘要：**
几何相对位置编码已成为将空间归纳偏置注入多视图 Transformer 的主要机制。现有设计将注意力条件化于相机级视锥或光线步进深度，通过传感器几何关联跨视图 token。然而，这种以传感器为中心的表述仅描述了 token 从何处被观测到，却未刻画该 token 所描绘场景区域的丰富表面几何。本文主张转向表面感知的位置编码，显式地将 patch token 建立在物理表面的几何之上。我们提出 HRoPE，它遵循经典多视图立体中的倾斜支撑窗口假设，将每个 patch 的局部几何表示为倾斜的 3D 平面。我们将 token 级、由平面诱导的单应性作为相对变换注入注意力。这使 Transformer 具备几何先验，用于校正透视畸变并对齐跨视角的 patch 特征。我们的编码无需真值几何：平面参数既可仅在新视图合成目标下端到端预测，也可从基础模型导出。在 RealEstate10K、CO3Dv2 和 DL3DV 上的大量实验表明，我们最佳的 HRoPE 变体在新视图合成上始终优于所评估的几何位置编码。大量消融与分析显示了所提编码的有效性。请参阅我们的项目页面：https://gaohchen.github.io/HRoPE

### 50. OverSeer：超越智能体所见的多智能体世界模型

**原文标题：** OverSeer: Multi-Agent World Models Beyond What Agents See

**摘要：**
尽管视频世界模型取得了成功，但将其扩展到多智能体场景仍然困难，因为这需要生成多个智能体特定的视频流，且这些视频流需在时间上以及不同智能体之间保持一致。为弥补这一空白，我们提出 OverSeer，一种多智能体世界模型，利用辅助相机视图增强智能体的自我中心视图。我们认为，通过将辅助视图在空间中固定，它们可作为以世界为中心的表征的代理：与智能体视图不同——智能体位置的简单变化即可使这些视图完全改变——辅助视图中的变化直接映射为世界状态的局部变化。我们表明，这些固定视图显著有助于模型保持一致性。我们还表明，由于其冗余和半静态特性，辅助视图可通过 delta-VAE 高效压缩，该模型仅编码相对于静态参考图像的变化，从而减少处理这些视图所需的 token 数量。在 Minecraft 和 Doom 中的实验表明，世界一致性和智能体一致性均得到改善；真实世界多相机采集的定性结果表明，该方法并不局限于游戏引擎。我们的压缩分析进一步表明，delta-VAE 显著降低了辅助视图生成的计算开销。我们得出结论：这些固定视图为改进多智能体世界模型提供了一种简单而高效的方法。
